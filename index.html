Pi session viewer

Turn shared Mermaid diagrams into polished interactive maps.

Point Pi's built-in /share command at this viewer with PI_SHARE_VIEWER_URL. The browser converts each Mermaid fence locally, with semantic colors, edge tracing, pan, zoom, fullscreen, and source controls. 

export PI_SHARE_VIEWER_URL="https://pi.narumi.dev/session/"
Secret Gists are unlisted, not private. Anyone with the link can read the complete session.
