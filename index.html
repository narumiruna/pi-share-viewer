Quick setup

Setup

Two steps. One shareable session.

Configure the viewer before starting Pi, then use the built-in command.

01

Set the viewer URL

Point Pi at this viewer before launch.

export PI_SHARE_VIEWER_URL="https://your-viewer.example/session/"
pi
02

Share from Pi

Run Pi's built-in sharing command.

/share

Share with care. Secret Gists are unlisted, not private.
