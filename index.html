Pi session viewer

Read complete Mermaid diagrams in shared Pi sessions.

Point Pi's built-in /share command at this viewer with PI_SHARE_VIEWER_URL, then inspect diagrams with pan, zoom, fullscreen, and source controls. 

export PI_SHARE_VIEWER_URL="https://pi.narumi.dev/session/"
Secret Gists are unlisted, not private. Anyone with the link can read the complete session.
